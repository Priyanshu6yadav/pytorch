# Pytorch Project

This repository contains code and resources for experiments and projects using PyTorch.

## Structure
- `tensor & setup/setting.ipynb`: Jupyter notebook for initial setup and tensor operations.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/Priyanshu6yadav/pytorch.git
   ```
2. Open the notebook in Jupyter or VS Code.

## Requirements
- Python 3.x
- PyTorch
- Jupyter Notebook or VS Code
